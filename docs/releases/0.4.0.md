## Start on login

- **New `service` subcommand**: `oh-my-http service install|status|uninstall` turns the current
  directory + flags into a user-level service and starts it right away.
  - macOS → `~/Library/LaunchAgents/cn.xs25.oh-my-http.<port>.plist` (`RunAtLoad` + `KeepAlive`)
  - Linux → `~/.config/systemd/user/oh-my-http-<port>.service` (`Restart=always`)
- The service runs `--foreground` (no double-daemon), logs to `<state-dir>/service-<port>.log`,
  and `install` warns when a manually started instance still holds the port.
- `--port=25250` style values are recognised (the port is not appended twice).

## Docs

- README (zh/en) gained a “Start on login / 开机自启” section, including the note that user-level services
  start after login and how to run before login (root LaunchDaemon / systemd system unit,
  or `loginctl enable-linger` on Linux).

## 开机自启

- **新增 `service` 子命令**：`oh-my-http service install|status|uninstall`，把当前目录与参数写成用户级服务并立即启动。
  - macOS → `~/Library/LaunchAgents/cn.xs25.oh-my-http.<port>.plist`（`RunAtLoad` + `KeepAlive`）
  - Linux → `~/.config/systemd/user/oh-my-http-<port>.service`（`Restart=always`）
- 服务内以前台方式运行（不会再多 fork 一个后台进程），日志写 `<state-dir>/service-<port>.log`；
  安装时会提示同端口的手动实例需要先 `stop`。
- `--port=25250` 这种写法也能识别，不会重复补端口。

## 文档

- README 中英文都补了「开机自启 / Start on login」章节，说明用户级服务是登录后启动，
  以及要不登录就启动该怎么做（root 级 LaunchDaemon / systemd system，或 Linux 上 `loginctl enable-linger`）。
