## Fixes

- **The folder picker footer was misaligned.** The “Choose” button reused the login page’s global
  `button.primary` style (`width: 100%`, `margin-top: 1.4rem`), which inflated the footer to 87px and made the
  two bottom buttons different heights. It now has its own `.mk-primary` class: the footer is back to 52px,
  both buttons are aligned, and the file list keeps a little bottom padding.

## Docs

- Screenshots for both READMEs (directory browsing, directory bindings, the Finder-style folder picker),
  with a separate set for the Chinese and the English UI.
- `docs/` now ships inside the npm tarball, so the images also render on the package page.
- Release notes can be written per version in `docs/releases/<version>.md`; otherwise they are generated
  from the matching CHANGELOG section (falling back to “未发布”).
